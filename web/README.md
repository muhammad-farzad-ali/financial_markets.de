# DAX 40, MDAX and SDAX web dashboard

`web/index.html` is generated by `scripts/web.py` from the same TSVs as
`reports/fundamentals.md`. It is a single, dependency-free static page:

- no framework, server, database or API;
- plain-language labels and short explanations so non-technical readers can
  interpret the scores and metrics;
- search, index/business-type/risk filters, sorting and expandable company
  details run in the browser;
- all numbers come from `data/fundamentals_metrics.tsv`,
  `data/fundamentals_scores.tsv` and `data/fundamentals_scenarios.tsv`.

## Regenerate

```bash
python3 scripts/web.py
```

Or as part of the full pipeline:

```bash
python3 scripts/run_all.py
make all
```

## View

Open `web/index.html` directly, or serve the repository root:

```bash
python3 -m http.server 8000
# http://localhost:8000/web/
```

The page links to `../reports/fundamentals.md` for the full methodology and
company-by-company narrative.
